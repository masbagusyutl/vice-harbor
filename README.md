Vice Harbor is an original 3D open-world crime game set in a neon coastal city. Walk the streets and the boardwalk, steal parked or moving cars and drive them, outrun the VHPD under a 0–5 wanted-star system, and run three chained story missions for Rico and Lena — with traffic, pedestrians, police pursuits, fist and gun combat, a live minimap HUD, and save/continue. Built with Three.js (WebGL), all geometry and sound generated in code, no external assets, no Rockstar material.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network requests at runtime.
